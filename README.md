# Search Agent

A LangChain search assistant that uses a local Ollama model and Tavily web search.

The agent:

- Searches the web using Tavily
- Uses Ollama for local language-model inference
- Returns structured responses using Pydantic
- Includes an answer and source URLs
- Uses LangChain's `create_agent` API

## Technologies

- Python 3.12+
- LangChain
- Ollama
- Tavily
- Pydantic
- uv

## Requirements

- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/)
- [Ollama](https://ollama.com/)
- A Tavily API key

## Installation

Install the project dependencies:

```powershell
uv sync

Response Structure
The model returns an intermediate response similar to:
```
{
  "results": [
    {
      "title": "Example result",
      "summary": "Summary of the result.",
      "source_index": 1
    }
  ]
}
```

Python then converts it into the final response:
```
{
  "results": [
    {
      "title": "Example result",
      "summary": "Summary of the result.",
      "source": "https://example.com/article"
    }
  ]
}
```

The source URL is taken directly from Tavily rather than generated by the model. This reduces hallucinated, missing, or incorrect links.
